# Contact Management System with Custom Modules

## Project Description
A Python-based Contact Management System
using Object-Oriented Programming and
Modular Architecture.

## Features
- Add new contacts
- Delete contacts
- Search contacts by name
- Display all contacts
- Email validation
- Phone number validation
- Duplicate email prevention

## Project Structure

Contact-Management-System/
│
├── contact_manager/
│   ├── __init__.py
│   ├── models.py
│   ├── services.py
│   └── utils.py
│
├── main.py
└── README.md

## Technologies Used
- Python
- Object-Oriented Programming
- Python Modules and Packages

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

python main.py

## Storage
Contacts are stored in an in-memory list.
